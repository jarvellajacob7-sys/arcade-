# Arcade Vault — Amazing Rope Police

A first-version static website for playing Amazing Rope Police in a browser.

## Files
- `index.html` — homepage/game library
- `play.html` — game player page
- `style.css` — styling

## Deploy
Upload the three files to a static host such as GitHub Pages, Netlify, or Vercel.

The player page uses the pinned Selenite commit through jsDelivr:
`selenite-cc/selenite-old@9c743188888af0986c8c7b293dbac8f9e421a4ee/amazing-rope-police/index.html`

## Important
The site does not copy the game's files into this package. It loads the pinned repository copy at runtime. Keep the source/license attribution and check the repository's license plus any third-party asset licenses before redistributing or mirroring the game.
